화면 공유 → 로드맵 영역 지정 → 자동 판독 → 패턴 분석 & 베팅 제안
먼저 읽어주세요. 바카라의 각 판은 독립 시행입니다. 과거 패턴은 다음 결과의 확률을 바꾸지 않으며, 어떤 패턴 분석도 하우스 엣지(뱅커 1.06% / 플레이어 1.24% / 타이 14.4%)를 이길 수 없습니다. 이 도구는 로드맵을 자동으로 읽고 통계를 보여주는 보조 도구이며, 추천은 "관측된 패턴을 따라가면 이 쪽"이라는 뜻일 뿐 예측이 아닙니다. 장기적으로 기대값은 항상 마이너스입니다. 실제 사이트에서의 화면 자동 판독은 해당 사이트 이용약관 위반일 수 있으니 본인 책임 하에 사용하세요.

1. 화면 공유 & 영역 지정

영역 상자 만들기를 누르면 초록 상자가 나타납니다. 상자 안쪽을 끌면 이동, 모서리·변의 네모 손잡이를 끌면 크기 조절입니다. (상자를 선택한 뒤 방향키로 1px 미세 이동, Shift+방향키로 크기 조절도 됩니다.) 로드맵 격자를 딱 감싸도록 맞추고, 행/열 수를 실제 칸 수와 맞추세요. 색 판별: 빨강=뱅커, 파랑=플레이어, 초록=타이.
