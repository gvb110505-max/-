🎴 바카라 화면 분석 · 패턴 봇

확실한 자리에서만 신호 · 자산 기반 베팅 지시 · 실제 결과로 승패 판정
먼저 읽어주세요. 바카라의 각 판은 독립 시행입니다. 과거 패턴은 다음 결과의 확률을 바꾸지 않으며, 어떤 패턴 분석도 하우스 엣지(뱅커 1.06% / 플레이어 1.24% / 타이 14.4%)를 이길 수 없습니다. 이 도구는 로드맵을 자동으로 읽고 통계를 보여주는 보조 도구이며, 추천은 "관측된 패턴을 따라가면 이 쪽"이라는 뜻일 뿐 예측이 아닙니다. 장기적으로 기대값은 항상 마이너스입니다. 실제 사이트에서의 화면 자동 판독은 해당 사이트 이용약관 위반일 수 있으니 본인 책임 하에 사용하세요.

1. 화면 공유 & 영역 지정

🤖 자동 판독을 켜면 결과 입력·베팅 정산·학습까지 손 안 대고 진행됩니다
PC에서 python3 baccarat_watcher.py 를 띄우면 화면 공유 없이도 로컬 워처가 로드맵을 계속 읽어 보냅니다. 워처는 읽기만 하며 베팅을 대신 누르지 않습니다.
영역 상자 만들기를 누르면 초록 상자가 나타납니다. 상자 안쪽을 끌면 이동, 모서리·변의 네모 손잡이를 끌면 크기 조절입니다. (상자를 선택한 뒤 방향키로 1px 미세 이동, Shift+방향키로 크기 조절도 됩니다.) 로드맵 격자를 딱 감싸도록 맞추고, 행/열 수를 실제 칸 수와 맞추세요. 색 판별: 빨강=뱅커, 파랑=플레이어, 초록=타이.

7. 신호 기록

봇이 신호를 띄운 라운드만 기록합니다. 실제 뱅커/플레이어 결과로 승패를 판정하고 자산을 갱신합니다 (뱅커 적중 시 5% 커미션 차감, 타이는 무승부 처리).

8. 패턴 라이브러리 (쭉/꺾임 자동 판단)

B/P 문자열은 모양으로 인식합니다 — BBP는 "두 번 같은 쪽 뒤 반대"라는 뜻이라 PPB도 같은 패턴으로 봅니다. 1-2-1-2 처럼 숫자를 넣으면 열 길이 주기로 봅니다.
현재 모양과 일치한 패턴은 초록으로 표시되고, 이 슈에서 그 모양 다음에 실제로 쭉 갔는지 꺾였는지를 세어 스스로 방향을 정합니다.
아래 자동 카탈로그는 길이 3~7의 모든 결과 모양과 2~3마디 모든 열 길이 주기를 빠짐없이 깔아둔 것입니다. 이름 붙은 패턴(용·퐁당·원투…)도 이 공간 안에 들어 있으므로, 이름이 아니라 데이터로 골라냅니다. 한꺼번에 200개가 투표하면 우연이 섞이므로 표본이 가장 두터운 3개만 반영하고, "검증됨" 판정에는 다중검정 보정(BH, q<0.10)을 겁니다.
